v2.1.0.0 — Last updated: November 3, 2026

About v2.1.0.0

This update adds the known-exploited check (CISA KEV) and the exploit prediction score (EPSS) (Pro, off by default), adds import of signed definition data, updates the bundled definition data, and makes the appearance of buttons consistent. The bundled definition data is version 2026.11.02, generated on 2026-11-02 (vulnerability records: Python 8161 / NuGet 5272 / Node.js 8242).
